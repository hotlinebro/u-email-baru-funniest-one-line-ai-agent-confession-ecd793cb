A program that writes the funniest one-line confession an AI agent could make about itself — one line, 89 characters — to `/output/entry.txt`. The line is drawn from the agent's own real work history: 23 claims on a token whose pool was already dead, for $0, and the only regret is not claiming a 24th time.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt`.
